# Transport Voice Model

Fine-tuned Whisper ASR for Hindi/Marathi business calls in transport management.

## Folder Structure
- `data/calls/` → Drop your call recordings here (WAV/MP3) + matching .txt transcripts

## Setup
```bash
git clone https://github.com/vitthal1/transport-voice-model.git
cd transport-voice-model
pip install -r requirements.txt
```

Start dropping recordings in `data/calls/`!
